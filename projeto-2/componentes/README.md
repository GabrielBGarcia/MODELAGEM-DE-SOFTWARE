# Componentes

Tudo o que é de componentes fica **nesta pasta**. Os componentes, pacotes, interfaces e portas estão na seção 5 do [`modelagem-do-sistema.md`](../modelagem-do-sistema.md) — use exatamente esses nomes.

## Integrante 4 – Diagrama

Coloque aqui:
- o **arquivo-fonte** da ferramenta (ex.: `componentes.puml` ou `componentes.drawio`);
- a **imagem** exportada (`componentes.png`).

O diagrama precisa ter: componentes dentro dos pacotes, interfaces fornecidas (pirulito) e requeridas (soquete), dependências com seta tracejada e portas.

## Integrante 5 – Dicionário e símbolos

Crie aqui dois arquivos:
- **`dicionario.md`** – para cada componente: o que ele faz, quais interfaces fornece e requer, e **por que** depende de cada uma.
- **`simbolos.md`** – o nome da ferramenta usada e uma tabela com cada símbolo dos dois diagramas e como a ferramenta o desenha.
