# Diagrama de Componentes

**Responsável:** [Integrante 4]

Desenhar o diagrama seguindo a seção 5 de [`../../docs/modelagem-do-sistema.md`](../../docs/modelagem-do-sistema.md): componentes dentro dos pacotes (Frontend, Backend, Dados, Serviços Externos), interfaces fornecidas (pirulito) e requeridas (soquete), dependências tracejadas e as portas sugeridas.

Colocar nesta pasta:
- o **arquivo-fonte** da ferramenta (ex.: `componentes.puml` ou `componentes.drawio`);
- a **imagem exportada** em boa resolução (`componentes.png` ou `.svg`).
