# Dicionário de Componentes e Tabela de Símbolos

**Responsável:** [Integrante 5]

Criar nesta pasta:

1. **`dicionario-de-componentes.md`** – para cada componente da seção 5 de [`../../docs/modelagem-do-sistema.md`](../../docs/modelagem-do-sistema.md): responsabilidade, interfaces que fornece, interfaces que requer e **por que** depende de cada uma.
2. **`tabela-de-simbolos.md`** – nome da ferramenta usada e uma tabela com cada símbolo que aparece nos dois diagramas (ator, caso de uso, fronteira, associação, generalização, include, extend, componente, pacote, interface fornecida, interface requerida, dependência, porta), com a imagem ou descrição de como a ferramenta o desenha.
