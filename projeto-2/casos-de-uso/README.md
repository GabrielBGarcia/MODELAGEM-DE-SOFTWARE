# Casos de Uso

Tudo o que é de casos de uso fica **nesta pasta**. Os nomes dos atores e dos casos de uso estão nas seções 3 e 4 do [`modelagem-do-sistema.md`](../modelagem-do-sistema.md) — use exatamente esses nomes.

## Integrante 2 – Diagrama

Coloque aqui:
- o **arquivo-fonte** da ferramenta (ex.: `casos-de-uso.puml` ou `casos-de-uso.drawio`);
- a **imagem** exportada (`casos-de-uso.png`).

O diagrama precisa ter: fronteira do sistema com o nome, atores, associações, generalização de atores, `<<include>>` e `<<extend>>`.
