# Diagrama de Casos de Uso

**Responsável:** [Integrante 2]

Desenhar o diagrama seguindo as seções 3 e 4 de [`../../docs/modelagem-do-sistema.md`](../../docs/modelagem-do-sistema.md): fronteira do sistema, atores (com as generalizações), associações, `<<include>>` e `<<extend>>`.

Colocar nesta pasta:
- o **arquivo-fonte** da ferramenta (ex.: `casos-de-uso.puml` ou `casos-de-uso.drawio`);
- a **imagem exportada** em boa resolução (`casos-de-uso.png` ou `.svg`).
